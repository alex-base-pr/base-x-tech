# Release 2026-09-25: design v2 to base-xtech.com

## How prod deploys
Push to `base-xtech/base-xtech` branch `live` → `.github/workflows/deploy-live.yml` → `npm ci && npm run build` (Node 18)
→ `rsync -avz --delete dist/` to the hosting. `staging` does the same to the staging path.
`--delete` removes every file on the server that is not in `dist` — the blog is served by the Cloudflare Worker on `/blog/`, not from that folder.

## Preconditions (checked)
- `upstream/live` (16c2853) and `upstream/staging` are ancestors of our `main` → fast-forward, no merge conflicts.
- Build passes under Node 18.20 (same as the workflow).
- `DEPLOY_ENV` unset in the workflow → prod mode: indexable, analytics + CookieYes on, real form endpoint (clickup.base-xtech.com).

## Steps
1. Merge `design-v2` → `main` (alex-base-pr/base-x-tech); dev.base-xtech.com rebuilds.
2. QA on dev: `QA_BASE_URL=https://dev.base-xtech.com npx playwright test` + manual pass on phone (menu, modal, language switch on Complex).
3. Owner OK → push `main` to upstream `staging`; check the staging site.
4. Owner OK → PR `staging` → `live` in base-xtech/base-xtech (or push); watch the Action.
5. After deploy: `QA_BASE_URL=https://base-xtech.com npx playwright test --project=chromium`; submit one real test lead through the modal and confirm it lands in ClickUp; Search Console → sitemap resubmit.

## Rollback
Commit a revert on `live` back to the tree of 16c2853 (`git revert --no-commit 16c2853..HEAD && git commit`) and push: the Action rebuilds and rsyncs the old site. No force-push needed.
